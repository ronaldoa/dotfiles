ranger 速查表                                            (,? 打开 · q 关闭 · / 搜索)

查找 / 跳转
  ,f        fzf 模糊搜索当前目录下的文件和目录(右侧预览),回车跳过去
  ,d        fzf 只搜目录
  ,z 关键词  zoxide 跳到常去的目录(Tab 补全)
  ,Z        zoxide 交互式挑选目录
  /  n  N   在当前列表里搜索 / 下一个 / 上一个
  gg  G     跳到顶部 / 底部
  gh  g/    回到家目录 / 根目录

选择 / 复制 / 移动
  空格      标记文件(可多选)        v  反选全部     uv  取消所有标记
  yy        复制                    dd  剪切        pp  粘贴
  yp  yn    复制路径 / 复制文件名
  cw        重命名                  a   在文件名末尾改名
  :mkdir 名字   新建目录            :touch 名字   新建文件

删除 / 回收站
  dD  Delete  移到回收站(多个或非空目录会先确认)
  dR          从回收站恢复当前目录下删掉的文件
  dX          永久删除(不可恢复)

压缩 / 解压
  ux        解压到同名文件夹(只有一个顶层项时不多套一层;GBK 中文名 zip 自动识别)
  uc        压缩选中的文件:回车 = .zip,Tab 换 .tar.gz / .7z / .tar.zst / .tar.xz
  uz        用 7z 直接解压到当前目录

显示
  zh        显示 / 隐藏 隐藏文件
  zp        开关预览              zi  开关图片预览
  o         排序方式(os 大小 · om 修改时间 · on 名字 · ot 类型;大写字母为倒序)
  dc        计算目录大小

其他
  S         在当前目录打开 shell(exit 或再敲 ranger 回到 ranger)
  !         执行命令:%s = 选中文件,%f = 当前文件,%d = 当前目录
  r         选择用什么程序打开
  q         退出(终端会停在 ranger 最后所在的目录)
  ?         ranger 完整帮助(k 看全部快捷键)
  u / d / g / , 等前缀键按下后稍等,底部会提示后续可以按什么
