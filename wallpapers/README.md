# wallpapers

桌面壁纸,stow 后链接到 `~/Pictures/wallpapers/`,用 `nitrogen` 选择。
当前用的是 `nord_mountains.png`。锁屏默认也用这张(见 `i3/.config/i3/bin/lock`)。

`nord_*`、`ign_*` 等 Nord 风格的图来自 [linuxdotexe/nordic-wallpapers](https://github.com/linuxdotexe/nordic-wallpapers)
(MIT 许可),文件名未改。
